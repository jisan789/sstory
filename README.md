# গল্প সংকলন (Bengali Story Collection)

একটি সুন্দর ও পরিচ্ছন্ন বাংলা গল্প পড়ার ওয়েব অ্যাপ, যা সরাসরি [Vercel](https://vercel.com)-এ হোস্ট করার জন্য সম্পূর্ণ প্রস্তুত।

---

## 🚀 Vercel-এ হোস্ট করার উপায় (৩টি সহজ পদ্ধতি)

### পদ্ধতি ১: GitHub দিয়ে Vercel-এ ডিপ্লয় (সবচেয়ে সহজ ও জনপ্রিয়)

১. এই ফোল্ডারটিকে আপনার GitHub একাউন্টে একটি নতুন রিপোজিটরিতে পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Vercel deployment"
   git branch -M main
   git remote add origin https://github.com/আপনার-ইউজারনেম/আপনার-রিপো-নাম.git
   git push -u origin main
   ```
২. **[vercel.com](https://vercel.com)**-এ লগইন করুন।
৩. **Add New...** > **Project** নির্বাচন করুন।
৪. আপনার GitHub রিপোজিটরিটি সিলেক্ট করে **Import** বাটনে ক্লিক করুন।
৫. **Deploy** বাটনে চাপ দিন। কয়েক সেকেন্ডের মধ্যে আপনার সাইট লাইভ হয়ে যাবে!

> পরবর্তীতে `stories.json`-এ কোনো গল্প যোগ করে গিটহাবে পুশ করলেই Vercel স্বয়ংক্রিয়ভাবে সাইট আপডেট করে দেবে।

---

### পদ্ধতি ২: Vercel CLI দিয়ে এক কমান্ডে ডিপ্লয়

আপনার টার্মিনালে নিচের কমান্ডটি রান করুন:
```bash
npx vercel
```
- প্রম্পট আসলে `y` চাপুন এবং লগইন সম্পন্ন করুন।
- প্রজেক্ট সেটিংস ডিফল্ট রেখেই এন্টার দিয়ে ডিপ্লয় সম্পন্ন করুন।
- সরাসরি প্রোডাকশনে ডিপ্লয় করতে:
  ```bash
  npx vercel --prod
  ```

---

### পদ্ধতি ৩: Vercel ড্যাশবোর্ডে Drag & Drop / CLI ছাড়া

আপনি যদি গিটহাব ব্যবহার না করতে চান:
1. `npx vercel` কমান্ড ব্যবহার করতে পারেন, অথবা
2. Vercel CLI ইন্সটল করে এক ক্লিকে ডিপ্লয় করতে পারেন।

---

## 📁 ফাইল পরিচিতি

- `index.html`: মূল অ্যাপ ইন্টারফেস ও রিডার ভিউ।
- `generator.html`: স্বয়ংক্রিয় বাংলা গল্প JSON জেনারেটর (কমা ও কোটেশন অটো-ফিক্স সহ)।
- `server.js`: বিল্ট-ইন জিরো-ডিপেনডেন্সি লোকাল সার্ভার ও অটো-সেভ API।
- `stories.json`: গল্পের ডাটাবেস (নতুন গল্প এখানে যুক্ত হয়)।
- `tracker.js`: ভিজিটর এনালিটিক্স ও টেলিগ্রাম নোটিফিকেশন সিস্টেম।
- `vercel.json`: Vercel ক্যাশিং হেডার, সিকিউরিটি হেডার ও ক্লিন URL কনফিগারেশন।
- `404.html`: কাস্টম বাংলা ৪০৪ এরর পেজ।
- `.gitignore`: অপ্রয়োজনীয় ও সিক্রেট ফাইল গিটহাব থেকে বাদ রাখার জন্য।

---

## ⚡ স্বয়ংক্রিয় JSON জেনারেটর

গল্প যোগ করতে গিয়ে JSON সিনট্যাক্স, কোটেশন মার্ক বা কমার ভুল এড়াতে বিল্ট-ইন জেনারেটরটি ব্যবহার করুন:
- ব্রাউজারে যান: `http://localhost:3000/generator.html`
- শুধুমাত্র **শিরোনাম**, **আইডি** (অটো-জেনারেটেড), **সংক্ষেপ** ও **প্যারাগ্রাফ** পেস্ট করুন।
- সিস্টেম স্বয়ংক্রিয়ভাবে প্রতিটি প্যারাগ্রাফ আলাদা করবে, কমা বসাবে এবং ১-ক্লিকে `stories.json` ফাইলে সেভ করে দেবে।

## 💻 লোকাল কম্পিউটারে রান করার নিয়ম

```bash
npm start
```
অথবা যেকোনো ব্রাউজারে সরাসরি `index.html` ওপেন করতে পারেন (অথবা VS Code-এর Live Server এক্সটেনশন দিয়ে রান করতে পারেন)।
